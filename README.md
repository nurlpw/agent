# Nurl

Агент Nurl открывает локальный HTTP-сервер по публичному адресу. Запустите приложение на своем компьютере, выполните `nurl 3000`, и оно станет доступно по ссылке вида `https://<id>.nurl.pw`. Агент держит соединение с сервером Nurl через WebSocket и пересылает запросы в ваше приложение, включая WebSocket-соединения. Подробнее на сайте [nurl.pw](https://nurl.pw).

## Установка

Windows:

```powershell
winget install Nurl.Nurl
```

Linux и macOS:

```sh
curl -fsSL https://nurl.pw/install.sh | sh
```

Готовые файлы для всех платформ лежат на странице [релизов](https://github.com/nurlpw/agent/releases). Рядом с каждым файлом есть `.sha256` с контрольной суммой.

## Использование

```sh
nurl 3000
```

Адрес можно указать как порт, как `localhost:5173` или полностью, например `http://127.0.0.1:8000`. Команда `nurl login` входит в аккаунт: туннели получают тариф аккаунта и видны в панели на сайте. На тарифе Pro можно открыть туннель на своем имени командой `nurl 3000 myshop`, тогда адрес будет `https://myshop.nurl.pw` и не изменится между запусками. Команда `nurl update` обновляет агента, `nurl logout` выходит из аккаунта, `nurl --help` показывает все параметры.

Агент учитывает переменные `HTTPS_PROXY`, `HTTP_PROXY`, `ALL_PROXY` и `NO_PROXY`. Токен входа хранится в `%APPDATA%\nurl\config.json` на Windows и в `~/.config/nurl/config.json` на Linux и macOS, путь можно переопределить переменной `NURL_CONFIG`. При открытии туннеля и входе агент сообщает серверу имя компьютера, операционную систему и свою версию, чтобы их можно было увидеть в разделе сессий.

## Сборка

Нужен Rust 1.88 или новее.

```sh
cargo build --release
```

Агент подключается к `https://nurl.pw`. Тесты запускаются командой `cargo test`.
